Project 1100002: (Dead-man-switch) Permission based Wallet, delivered as Epora
Milestone 5: Finalization and Mainnet launch

A. Output: Mainnet beta prototype

Delivered: Epora is available on Cardano mainnet as a beta. The application provides a web interface for smart wallets with configurable permissions. The reference script is deployed. Confirmed mainnet transactions show wallet creation, funding, an operator spend, and a settings update that configured a beneficiary and a 30-day proof-of-life period. A later operator spend also advanced the proof-of-life deadline.

The 26 September 2026 evidence snapshot records two wallets under the current deployed policy. They hold 27 ADA in wallet outputs and another 3.788490 ADA in separate state deposits. These are prototype activity measurements, not a count of independent users. The beta remains explicitly unaudited.

Acceptance criteria: A working mainnet prototype. The final milestone requires a beta launch because the code has not been externally audited.

D. Output: Project Completion Report

Delivered: The report uses Catalyst's current headings: Deliverables, Usage, Impact, and Sustainability. It describes the contract system, application, API, intended users, and user workflow. It includes the approved Milestone 1, 2, and 3 references, measured mainnet activity, transaction fees, feedback results, and the closeout video link.
